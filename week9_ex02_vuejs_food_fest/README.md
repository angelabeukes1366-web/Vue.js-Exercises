# Food Fest Ticket Landing

## Overview

A Vue 3 single-page landing page for Cape Town Food Fest.

Features:

- Bronze, Silver and Gold ticket tiers
- Featured ticket highlighting
- Favourite button interaction
- Responsive layout
- Vue components and props

## Installation

```bash
npm install
npm run dev
```

## Technologies

- Vue 3
- Vite
- CSS
